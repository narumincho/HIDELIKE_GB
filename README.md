# HIDELIKE_GB

ブラウザ上で動作する、プチコン3号版 **HIDELIKE GB**
の移植プロジェクトです。原作のプログラムとアセットは [`original/`](./original/)
に保持しています。

## 起動・確認

```sh
deno task dev
deno task check
```

## 原作との差分と再現状況

原作の挙動を基準に確認し、意図して変更しない部分はこの表で管理します。

| 項目                       | 状態     | 内容                                                                                                 |
| -------------------------- | -------- | ---------------------------------------------------------------------------------------------------- |
| 箱の射出                   | 修正済み | 原作どおり壁判定なしで `16 + 16 + 9` px 移動する。                                                   |
| 箱の連射                   | 修正済み | キーボード長押しで連続射出せず、押した瞬間に1個射出。最大3個・循環上書きは原作どおり。               |
| BGM48の開始                | 修正済み | マップ19（リザルト画面）から再生する。                                                               |
| マップ21の移動速度         | 修正済み | X座標 `64 < x <= 96` の区間では速度を `÷4.5` にする。                                                |
| マップ13・15の敵の向き変更 | 修正済み | 敵ごとの選択不可方向を原作に合わせる。                                                               |
| クリアタイム               | 修正済み | マップ19に入った時点の値を記録し、リザルトとエンディング判定に使う。                                 |
| 更新周期                   | 修正済み | 原作どおり60 Hz固定（`VSYNC 1` 準拠の Accumulator 方式固定タイムステップ）。                         |
| 壁際の移動                 | 修正済み | 原作どおり足元1点判定 `(px, py + 8)` で壁接触時にX/Y両方を巻き戻す（壁ずり防止）。                   |
| MMLの音色・変調            | 修正済み | `@310` ノイズ音源（箱設置音・箱消滅音・ドラムトラック）をWeb Audioで再現。                           |
| エンディング演出           | 修正済み | 原作のフレーム単位待機・フェードイン（GBT2→GBT1→GBT0）および条件付き一枚絵表示シーケンスを完全再現。 |
| タイトルAPNG生成           | 修正済み | ビルド時に `original/HIDEL_GBSP.grp` から 3フレーム合成した `title.apng` を自動生成。                |
| タイトル表示               | 修正済み | 原作にない「PUSH SPACE / ENTER」等の追加表示を削除。                                                 |
